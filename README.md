# Bulls and Cows

Игра «Быки и коровы»: компьютер загадывает число из уникальных цифр, игрок угадывает,
получая после каждой попытки число bulls (цифра на своём месте) и cows (цифра есть,
но не на месте).

Проект выполнен в рамках задания RS School. Цель — не интерфейс, а архитектура:
игровая логика написана в функциональном стиле (чистые функции, иммутабельность,
HOF, каррирование, мемоизация, рекурсия) и разработана по TDD.

## Демо

[Открыть игру](https://Artynskij.github.io/bulls-and-cows/)

## Возможности

- Длина секрета 2–6, системы счисления: bin / oct / dec / hex.
- Ввод фильтруется по допустимым символам; hex принимается в любом регистре.
- История попыток с bulls/cows, иммутабельно пополняется.
- Завершение игры при угадывании, подсчёт попыток и времени.
- Таблица рекордов в `localStorage` (топ-10 по попыткам, затем по времени).
- «Новая игра» без перезагрузки страницы.

## Стек

- TypeScript (компиляция `tsc` в ES-модули, без бандлера)
- Vitest
- ESLint + Prettier
- Husky (pre-commit: lint-staged; pre-push: тесты)
- GitHub Actions → GitHub Pages

## Запуск

```bash
npm install
npm run build      # tsc → dist/
npm test           # тесты (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```
